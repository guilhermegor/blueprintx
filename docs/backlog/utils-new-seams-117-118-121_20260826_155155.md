## Defects found and fixed along the way (not in the original issue text)

- **MVC email opt-in nesting bug**: `copy_shared_utils` (unconditional) now ships
  `src/utils/email/` before `conditional_copy_email` (opt-in) copies the adapter package into
  the SAME directory. The old `cp -r optional/email dst` nests when `dst` exists
  (`utils/email/email/…`). Fixed in `python_mvc_service.sh` / `python_mvc_service_orm.sh`:
  `mkdir -p` + `cp -r optional/email/. dst/` (merge, not nest).
- **Scaffold copy-list drift** (the exact failure mode `feedback_scaffold_copylist_drift`
  warns about): all 4 service scaffolds hand-maintain a flat `utils=(...)` array; the
  `outlook_gateway` entry pointed at a path that no longer exists after the `ms_office/` move.
  Fixed in all 4 (`python_ddd_service.sh`, `python_ddd_service_orm.sh`,
  `python_mvc_service.sh`, `python_mvc_service_orm.sh`): replaced with `ms_office`, added
  `xml_reader` and `email`. The per-util test-copy step assumed one `test_${util}.py` per
  entry; `ms_office`/`email` each ship multiple test files, so the copy step is now a glob
  (`test_${util}*.py`) in all 4 — required renaming `test_excel_sheet_names.py` to
  `test_ms_office_excel_sheet_names.py` so it matches the `ms_office` glob.
  `python_lib_minimal.sh` has its OWN curated module list (private `_internal/utils/`); added
  `xml_reader.py` there too (deptry caught the unused `defusedxml` dependency immediately).
- **Cross-module `FileContract` identity mismatch in tests**: `xml_reader.py` imports
  `FileContract` bare (`from utils.tabular_reader import …`, correct for runtime — there is no
  `src.` prefix outside pytest's dual `pythonpath`). A test importing `FileContract` via
  `from src.utils.tabular_reader import …` loads a SECOND, distinct module instance, and the
  runtime type-checker then rejects a contract built from one instance when `read_xml` expects
  the other. Fixed by importing `FileContract`/`ContractError` bare in `test_xml_reader.py`,
  matching how `xml_reader.py` itself resolves them.
- **`tests/` complexity cap (1)**: two `test_email_sender.py` tests defined a nested nested
  function as a fake sender, which the mccabe counter charges against the enclosing test.
  Rewritten with `mocker.Mock(...)` instead of a nested `def`.
